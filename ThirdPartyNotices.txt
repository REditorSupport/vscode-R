The List Viewer uses the package's CSS and icon font. The icon artwork is
unchanged.

The extension also includes SVG copies of the open-preview, preview, globe,
graph and help icons in images/icons/dark and images/icons/light, with colors
set for the corresponding themes. These are used for viewer tab icons,

webR JavaScript API
-------------------

The extension bundles the JavaScript API from webR 0.6.1. Copyright 2023 webR
authors. The distribution's licensing terms are included in
dist/resources/webr-LICENSE.md. Runtime binaries and R packages are retrieved
from their upstream distributions when the user starts webR.
https://github.com/r-wasm/webr/tree/v0.6.1

jsonlite Wasm viewer runtime
---------------------------

The viewer runtime includes a reduced copy of the jsonlite Wasm package.
The source distribution is https://cran.r-project.org/package=jsonlite.
The Wasm binary and checksum are pinned in src/webr/packages.json.
